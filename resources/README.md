# Descent shareware resources

These are the original Descent 1.4 shareware data files.  They were
extracted without modification from the PC shareware archive maintained by
the DXX-Rebirth project:

- Documentation: https://github.com/dxx-rebirth/dxx-rebirth/blob/master/INSTALL.markdown
- Archive: https://icculus.org/d2x/data/desc14sw.tar.gz
- Retrieved: 2026-08-24

The game data required by Descent-compatible engines is:

- `descent.hog`
- `descent.pig`

`SHAREWARE_README.TXT` is the release note distributed with Descent 1.4.  It
contains the original copyright and distribution terms; in particular, the
shareware release may be freely distributed in unmodified form without a
fee.  The registered/full-game data is not included here and is not freely
distributable.
